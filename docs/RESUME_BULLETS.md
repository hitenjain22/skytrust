In a cost-loss decision analysis it captured 52% of a perfect forecast's value vs 36% for NOAA's blend.
- Shipped a Streamlit app with live 7-night outlooks, per-site track records, and graceful API-failure fallback; models are exported to JSON and served with numpy, with CI running an offline test suite on every push.
